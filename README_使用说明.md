# 均衡随机分班工具

这个工具可以读取 Excel 学生名单，按用户输入的分班依据均衡随机分班，并把结果写回原 Excel 的一个新工作表里。

## 双击使用

1. 双击 `启动分班工具.bat`。
2. 小程序不会自动扫描电脑或文件夹里的 Excel；请点“选择”手动指定要分班的名单。
3. 点“生成模板”，得到 `分班名单模板.xlsx`；也可以直接选择已有报名导出表。
4. 在“根据哪些项分班”输入 `A`、`AB`、`ABC` 或 `ABCD`。
5. 如需定向安排，在名单中增加或填写 `是否定向` 和 `指定班级`，例如 `2班`。
6. 点“开始分班”。工具会在原 Excel 中新增或更新 `分班结果` 页面，不另存新文件。

工具只会新增或更新 `分班结果` 这个工作表，不会向原学生名单页写入内容，也不会修改原学生名单页的单元格、格式、筛选或公式。

班级名称请用中文逗号 `，` 隔开，并且数量要和“班级数量”一致。例如班级数量填 `5`，班级名称应填写：

```text
一班，二班，三班，四班，五班
```

如果班级数量和班级名称个数不一致，点击“开始分班”时会先弹窗提醒补齐或删减，不会直接开始读取名单分班。

分班依据选项：

- `A`：性别
- `B`：户籍大类，即上海市户口、外省市户口
- `C`：户籍细类，即本市人户一致、本市人户分离、外省市满积分、外省市不满积分
- `D`：儿童人员类型

例如：输入 `A` 只均衡男女；输入 `AB` 均衡男女和户籍大类；输入 `ABC` 同时均衡男女和户籍细类；输入 `ABCD` 再加入儿童人员类型。

## 推荐分班依据：ABC

如果分班要求是“按照学生性别、户籍信息，并将户籍细分为本市人户一致、本市人户分离、外省市满积分、外省市不满积分进行均衡随机分班”，建议在小程序的“根据哪些项分班”中填写：

```text
ABC
```

`ABC` 的含义是：

- `A = 性别`
- `B = 户籍大类`
- `C = 户籍细类`

其中 `B = 户籍大类` 包含：

- 上海市户口
- 外省市户口

其中 `C = 户籍细类` 包含：

- 本市人户一致
- 本市人户分离
- 外省市满积分
- 外省市不满积分

填写 `ABC` 后，程序会按“性别 + 户籍大类 + 户籍细类”的组合来尽量均衡随机分班。例如：

- 男 + 上海市户口 + 本市人户一致
- 女 + 上海市户口 + 本市人户分离
- 男 + 外省市户口 + 外省市满积分
- 女 + 外省市户口 + 外省市不满积分

具体分班方法：

1. 先处理定向安排学生，直接放进指定班级。
2. 其他学生按 `性别 + 户籍大类 + 户籍细类` 分成若干小组。
3. 每个小组内部随机打乱。
4. 再尽量把同一小组的学生平均分到各班。
5. 如果填写了随机种子，在名单和设置不变时，可以复现同样的分班结果。

不同输入的区别：

- 填 `A`：只按性别均衡，不符合完整户籍均衡要求。
- 填 `AB`：按性别和户籍大类均衡，但没有细分到本市人户一致、本市人户分离、外省市满积分、外省市不满积分。
- 填 `ABC`：正好符合“性别 + 户籍大类 + 户籍细类”的完整均衡要求。
- 填 `ABCD`：在 `ABC` 基础上额外加入“儿童人员类型”均衡。

原 Excel 会新增或更新一个 `分班结果` 页面，里面包含：

- `分班结果`：每名学生的最终班级。
- 按班级排序后的学生名单。
- 页面最下端的未参与分班学生行。
- 班级统计、分层明细、运行信息、异常和跳过说明。
- 班级名单按班级分段显示：先显示 `1班`，下面列出该班学生，再显示 `2班`，依次排列。
- 每个班级名单末尾会根据选择的分班依据生成比例饼图；例如选择 `A` 会生成男女比例图，选择 `ABC` 会生成性别、户籍大类、户籍细类比例图。
- 同一个班级的所有比例图会横向排成一行；图表信息显示在图上，不再额外占用多行显示“类别/人数”等说明表。
- 饼图会按类别数量和同一行图表数量自动调整大小与间距，尽量保证标签清晰可见，同时限制最大尺寸，避免图表过大。
- 班级统计、分班说明、运行信息、异常和跳过说明，均保留为清楚的表格形式。
- 如果 `每班上限 × 班级数量` 容纳不了参与分班的学生，会自动新增班级，并在页面第一行写明原因。

注意：因为结果要写回原 Excel，请先关闭正在打开的名单文件，再点击“开始分班”。

数据页保护规则：原学生名单页只用于读取，不用于写入。再次分班时，程序只会替换旧的 `分班结果` 页面，不会覆盖原学生名单。

隐私规则：程序不会自动扫描本机已有 Excel 文件，也不会读取历史文件。只有手动选择名单并点击“开始分班”后，才会读取该被选中的文件。

## 依赖安装与常见报错

`requirements.txt` 是程序运行需要的 Python 依赖清单，不是学生名单，也不会保存学生信息。目前主要依赖是 `openpyxl`，用于读取、写入 Excel 和生成图表。

如果没有安装依赖，可能会出现这些报错：

- `ModuleNotFoundError: No module named 'openpyxl'`
- `ImportError: No module named openpyxl`
- `缺少 openpyxl。请先安装：python -m pip install openpyxl`
- 双击 `启动分班工具.bat` 后窗口一闪而过，或提示缺少 Python 模块。

解决方法：

1. 在本工具所在文件夹空白处按住 `Shift` 并点鼠标右键，选择“在此处打开 PowerShell 窗口”。
2. 执行：

```powershell
py -m pip install -r requirements.txt
```

如果电脑不支持 `py` 命令，可以改用：

```powershell
python -m pip install -r requirements.txt
```

如果提示 `pip` 不存在，先执行：

```powershell
py -m ensurepip --upgrade
py -m pip install -r requirements.txt
```

如果提示 `py` 或 `python` 不是内部或外部命令，说明电脑可能没有安装 Python，或安装时没有加入 PATH。需要先安装 Python 3，再重新执行上面的安装命令。

## 命令行使用

生成模板：

```powershell
python class_splitter.py --create-template 分班名单模板.xlsx
```

执行分班，默认写回原 Excel 的 `分班结果` 页面：

```powershell
python class_splitter.py 分班名单模板.xlsx --class-count 4
```

按指定依据分班：

```powershell
python class_splitter.py 学生名单.xlsx --balance ABCD
```

指定班级名称：

```powershell
python class_splitter.py 学生名单.xlsx --classes "一班,二班,三班,四班"
```

固定随机种子，让结果可复现：

```powershell
python class_splitter.py 学生名单.xlsx --seed 20260627
```

设置每班人数上限：

```powershell
python class_splitter.py 学生名单.xlsx --capacity 36
```

## 名单字段

基础必填列：

- `姓名`
- `性别`：男、女

如果选择 `B` 或 `C`，工具会优先从以下字段自动判断户籍：

- `户籍地址(省)`
- `儿童人户分离登记情况`
- `儿童人员类型`
- `居住证类型`
- `报名情况`
- `分配验证点`
- `备注1` 至 `备注4`

也可以直接增加或填写：

- `户籍大类`：上海市户口、外省市户口
- `户籍细类`：本市人户一致、本市人户分离、外省市满积分、外省市不满积分

可选列：

- `是否定向`：是、否
- `指定班级`
- `备注`
